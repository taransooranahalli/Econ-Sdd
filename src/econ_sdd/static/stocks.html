Connect your personal data source

Set up Alpaca locally.

Create an Alpaca account with paper access and review its current free Basic data terms. This app uses the IEX feed. There is no paid upgrade, funding step or trading connection in Finance.

  1. Create your local Finance account using Sign in.
  2. In Alpaca, generate your paper API key and secret. Keep them private.
  3. In a local terminal, open this project and run the setup command below with your Finance username. The command prompts for keys with hidden input and saves an owner-bound private profile.
  4. Restart Finance, sign in, then return to Stocks and search. First access verifies your actual permissions; setup alone does not prove live access.
cd /Users/saint/Econ-Sdd
.venv/bin/python -m econ_sdd.market setup --username YOUR_FINANCE_USERNAME

Never paste keys into chat, GitHub, browser code or a public deployment. Stock prices stay in temporary server memory. See Alpaca’s market-data documentation ↗ for current account access and feed limits. Public redistribution requires a separate review.
